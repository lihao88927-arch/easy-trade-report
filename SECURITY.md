# Security policy

## Credentials

UN Comtrade subscription keys must be supplied through an environment variable. Do not include a real key in source files, issue reports, screenshots, fixtures, raw CSV files, or generated Markdown.

If a key is accidentally committed, revoke or rotate it in the UN Comtrade developer portal before removing it from Git history.

## Reporting a vulnerability

Open a private security advisory in the hosting repository. Include the affected version, reproduction steps, and impact. Do not publish active credentials or sensitive raw data in the report.
